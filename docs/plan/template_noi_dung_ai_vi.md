## AI GENERATION INSTRUCTIONS

1. **Chọn Template**: Service page → District, Ward page → Phường, Problem guide → Educational, Combination → District + Problem

2. **Populate Variables**: Fill TẤT CẢ {VARIABLE} instances

3. **Tùy Chỉnh**: Add local stats, mention landmarks, use district-specific angle

4. **Quality Checks**:
   - Flesch > 60
   - Keyword density 0.8-1.2%
   - No stuffing (natural)
   - 1+ user value per 200 words

5. **Metadata**:
   - Title: Keyword first, <60 chars
   - Meta description: 150-160 chars, keyword + CTA
   - Slug: {keyword}-{district}.html
   - Schema: LocalBusiness + Service + FAQ

6. **Media**:
   - Images: Alt text có keyword
   - Video: YouTube embed with transcript
   - Maps: Service area map

7. **Internal Linking**:
   - District pages → Problem pages (2-3)
   - Problem pages → District pages (2-3)

8. **Publishing**:
   - Publish Tue/Thu, 10 AM Vietnam time
   - Schedule via WordPress bulk tool
   - Submit sitemap to GSC
   - Monitor indexing in GSC
