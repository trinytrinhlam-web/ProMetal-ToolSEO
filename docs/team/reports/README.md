# Báo cáo

Báo cáo của agent nộp vào đây, tên file `T-xxx-<mã-agent>.md` (ví dụ `T-001-la-chan.md`).

- Báo cáo công việc: mẫu `../templates/report.md`
- Biên bản bảo mật của Lá Chắn: mẫu `../templates/security-review.md`
- Sự cố: `SU-CO-YYYY-MM-DD.md` (xem `../security.md` mục 7)

Báo cáo đã nộp không sửa lại; cần bổ sung thì thêm mục "Bổ sung ngày …" ở cuối.
